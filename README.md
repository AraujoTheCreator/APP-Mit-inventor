## 🛠 Tecnologias Utilizadas

- MIT App Inventor
- Android
- Componentes nativos da plataforma
- Armazenamento local (quando aplicável)


## 🚀 Como Executar

### 1. Importar o Projeto

1. Acesse o MIT App Inventor.
2. Faça login em sua conta.
3. Selecione:
   - Projects → Import project (.aia) from my computer
4. Escolha o arquivo `.aia` presente neste repositório.

### 2. Testar a Aplicação

O aplicativo pode ser executado através de:

- MIT AI2 Companion
- Emulador Android
- Instalação direta do APK
